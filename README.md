# 🚀 TaskFlow - Arquitectura Full Stack

TaskFlow es una aplicación de gestión de tareas basada en arquitectura cliente-servidor.

---


🔗 **Prueba Aquí**  
👉 https://taskflow-project-three-pi.vercel.app  

---

##  Funciones

Todo lo que necesitas, sin complicaciones:

- ➕ Añadir tareas en segundos  
- ✏️ Edición inline (doble click)  
- 🔍 Búsqueda en tiempo real  
- 🎯 Filtros inteligentes (todas / pendientes / completadas)  
- ✅ Marcar tareas como completadas  
- 🗑️ Eliminar tareas fácilmente  
- 📊 Estadísticas automáticas  
- 🌙 Modo oscuro persistente  

---

## Arquitectura

### Frontend
- Vanilla JS
- Fetch API (capa de red en `src/api/client.js`)
- UI reactiva basada en estados:
  - loading
  - error
  - success

### Backend
- Node.js + Express
- Arquitectura en capas:
  - routes
  - controllers
  - services
  - config

---


## ¿Por qué TaskFlow?

Porque las apps de tareas suelen ser:

❌ Demasiado complejas  
❌ Demasiado pesadas  
❌ Llenas de cosas que no usas  

👉 **TaskFlow va directo al grano.**
